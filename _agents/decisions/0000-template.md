# Architecture Decision Records (ADR)

Each ADR is one page, decided BEFORE implementing. Naming: `NNNN-short-slug.md`,
monotonically increasing.

## Template

```markdown
# NNNN. Title

- **Status:** proposed | accepted | superseded by NNNN | deprecated
- **Date:** YYYY-MM-DD
- **Deciders:** @handles
- **Context:** why do we need to decide now?
- **Options considered:** A / B / C (with trade-offs)
- **Decision:** which, and why
- **Consequences:** what this enables / costs / blocks
```
